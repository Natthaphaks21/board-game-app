# BoardBuddies Demo UI

This folder contains a non-production UI demo to quickly confirm visual flow and key features.

## Open demo

- Open `folder_demo/demo-ui.html` directly in your browser.
- No backend required.

## What is shown

- Login + onboarding flow
- Home summary cards
- Create party wizard (manual location mode)
- Join party list
- My parties + pending requests
- Party lobby + check-in state
- Borrow game UI with image cards

This is only a showcase interface and does not persist data.
